# Laravel Tasks & Users CRUD System

نظام إدارة شامل للمهام والمستخدمين مع نظام الصلاحيات والأدوار.

## 🚀 طريقة التشغيل

### 1. تثبيت الحزم
```bash
composer install
```

### 2. إعداد قاعدة البيانات
قم بإنشاء ملف `.env` وحدد بيانات قاعدة البيانات الخاصة بك:
```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=your_database_name
DB_USERNAME=your_username
DB_PASSWORD=your_password
```

### 3. إنشاء قاعدة البيانات وتشغيل الـ Seeders
```bash
php artisan migrate:fresh --seed
```

### 4. تشغيل المشروع
```bash
php artisan serve
```

ثم افتح المتصفح على: `http://localhost:8000`

## 👥 بيانات تسجيل الدخول

### حساب Admin (مدير النظام)
- **البريد الإلكتروني:** `admin@example.com`
- **كلمة المرور:** `password`
- **الصلاحيات:**
  - ✅ إدارة المستخدمين (CRUD كامل)
  - ✅ إدارة المهام (CRUD كامل)
  - ✅ رؤية جميع المستخدمين

### حساب User (مستخدم عادي)
- **البريد الإلكتروني:** `user@example.com`
- **كلمة المرور:** `password`
- **الصلاحيات:**
  - ❌ لا يمكنه الوصول إلى إدارة المستخدمين
  - ✅ يمكنه إدارة المهام الخاصة به فقط

## 🎯 تجربة النظام

### كيف تجرب كـ Admin؟

1. **افتح المتصفح:** `http://localhost:8000/login`
2. **سجل دخول بحساب Admin:**
   - Email: `admin@example.com`
   - Password: `password`
3. **ستظهر لك الصفحة الرئيسية مع الأزرار:**
   - 🏠 الرئيسية
   - 👥 إدارة المستخدمين (فقط للـ Admin)
   - 📋 إدارة المهام
   - تسجيل الخروج

4. **إدارة المستخدمين (Admin فقط):**
   - اضغط على "👥 إدارة المستخدمين"
   - ستظهر قائمة بجميع المستخدمين
   - يمكنك: إضافة مستخدم جديد، تعديل مستخدم، حذف مستخدم
   - يمكنك تحديد دور المستخدم (Admin أو User)

5. **إدارة المهام:**
   - اضغط على "📋 إدارة المهام"
   - يمكنك إضافة مهمة جديدة
   - تعديل المهام الموجودة
   - تغيير حالة المهمة (معلقة / مكتملة)
   - حذف المهام

### كيف تجرب كـ User عادي؟

1. **سجل دخول بحساب User:**
   - Email: `user@example.com`
   - Password: `password`

2. **ستظهر لك الصفحة الرئيسية مع:**
   - 🏠 الرئيسية
   - 📋 إدارة المهام (متاح)
   - ❌ **لا يوجد زر "إدارة المستخدمين"** (لأنك User وليس Admin)

3. **إذا حاولت الوصول إلى `/users` يدوياً:**
   - ستظهر رسالة خطأ: "User does not have the right roles"
   - لأن الصفحة محمية بـ Middleware `role:admin`

4. **يمكنك فقط إدارة المهام:**
   - إنشاء مهام جديدة
   - تعديل المهام
   - حذف المهام
   - تغيير حالة المهام

## 🔐 حماية الملفات

### Routes المحمية بـ Admin فقط:
- `/users` - عرض المستخدمين
- `/users/create` - إنشاء مستخدم
- `/users/{id}/edit` - تعديل مستخدم
- `/users/{id}` - تحديث/حذف مستخدم

### Routes المحمية بـ تسجيل الدخول:
- `/tasks` - إدارة المهام (لجميع المستخدمين المسجلين)
